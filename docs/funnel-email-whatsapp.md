# מה צריך כדי להפעיל (תשתית — דורש החלטות שלך)
1. **ספק מיילים** — Resend / Klaviyo / Mailchimp? (אני ממליץ Klaviyo לאיקומרס: יש לו אינטגרציה לשופיפיי + אוטומציות מובנות).
2. **נתוני עגלה נטושה** — Shopify Abandoned Checkouts API (קיים), או דרך Klaviyo.
3. **ווצאפ** — יש לנו תשתית Evolution. לשיווק ייזום (broadcast) צריך WhatsApp Business API מאושר עם תבניות (templates) מאושרות. עדכוני הזמנה אפשר כבר עכשיו.
4. **קוד הנחה** — להחליט אם נותנים תמריץ קטן במייל האחרון של עגלה נטושה.
5. **אישור דיוור (opt-in)** — חובה למיילים ולווצאפ שיווקי.
