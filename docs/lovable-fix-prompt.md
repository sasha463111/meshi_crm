# פרומפט תיקון ל-Lovable (העתק-הדבק)

מבוסס על ניתוח הקלטות Microsoft Clarity (ראה `clarity-behavioral-analysis.md`).
מטרה: לסגור את נטישת הסל (81%) שמקורה בבעיות UX במובייל.

```
האתר שלי (חנות מצעים) סובל מנטישת סל גבוהה במובייל (92% מהגולשים במובייל).
ניתחתי הקלטות Microsoft Clarity ומצאתי בעיות UX קריטיות. תקן את הבאות לפי סדר עדיפות:

1. כפתור "הוספה לעגלה" — במובייל יש המון "dead clicks" עליו (לחיצות שלא מגיבות).
   - ודא שהכפתור מגיב מיידית בלחיצה ראשונה, בלי השהיה.
   - הגדל את אזור הלחיצה (min 44x44px), הוסף משוב ויזואלי מיידי (loading/✓).
   - ודא שאין אלמנט שקוף שחוסם את הלחיצה.

2. עמוד /bundle (בונה המבצע 4 ב-219) — בורר הכריות/מגבות המתנה ("בחרו סוג כרית",
   "כריות מתנה בחרו") מקבל עשרות dead clicks ו-rage clicks במובייל = שבור/לא מגיב.
   - תקן שכל אפשרויות הבחירה (כרית/מגבת/תוספת) לחיצות ומגיבות מיידית במובייל.
   - הגדל אזורי לחיצה, הוסף מצב "נבחר" ברור, ודא שאין חפיפת אלמנטים.
   - פשט את הזרימה: בחירת 4 מצעים → תוספות → לסל, בלי קפיצות.

3. מעבר מ-/cart ל-checkout — 100% מהגולשים נתקעים בעגלה ולא ממשיכים.
   - הוסף כפתור "המשך לתשלום" גדול, בולט, דביק (sticky) בתחתית עמוד העגלה במובייל.
   - הצג מד התקדמות למשלוח חינם: "עוד ₪X למשלוח חינם מעל ₪299".
   - הצג בבירור את חיסכון המבצע בעגלה.

4. מהירות מובייל — זמן מעורבות ממוצע 18 שניות בלבד.
   - ודא טעינה מהירה של עמוד הקולקציה והמוצר במובייל, תמונות אופטימליות (lazy load).

הקהל מגיע כמעט כולו מפרסום פייסבוק/אינסטגרם ישר לעמוד /collections/bedding —
ודא שהחוויה שם מהירה וחלקה במובייל.
```
