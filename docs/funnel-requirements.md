# מה צריך כדי להפעיל את המשפך (תשתית)

המשפך עצמו (קופי + רצפים + תזמונים) מוכן בקובץ `funnel-email-whatsapp.md`.
כדי להפעיל אותו בפועל (שליחה אוטומטית) צריך את ההחלטות הבאות.

## ✅ מה שכבר יש (אשתמש אוטומטית)
- **הזמנות + לקוחות** (שם, טלפון, מייל) מ-Shopify
- **מוצרים** (שמות, תמונות, מחירים) — להצגת הפריט הננטש בהודעה
- **המבצע** (4 ב-219, משלוח חינם 299) — כתמריץ
- **Clarity** — מתי ואיפה נוטשים
- **WhatsApp (Evolution)** — תשתית שליחה

## 🔑 מה שצריך להחליט/להביא

**1. נוטשי סל אמיתיים (הכי קריטי)**
- האם Shopify "Abandoned Checkouts" מופעל? (שם יושבים מייל+טלפון+תוכן הסל). זה הדלק של המשפך.
- אם לא — נתפוס את הסלים בדרך אחרת (דרך האתר/Lovable).

**2. שליחת מיילים — איזה שירות?**
- חשבון **Resend / SendGrid / Mailgun / Klaviyo** (Resend הכי פשוט וזול; Klaviyo הכי חזק לאיקומרס).
- **דומיין שולח מאומת** — למשל `noreply@meshitextile.co.il` (כדי לא ליפול לספאם).

**3. WhatsApp — אישור שיווקי**
- האם המספר הוא **WhatsApp Business API** עם **תבניות מאושרות**? (חובה לשליחת שיווק יזום).
- אם זה Evolution על מספר רגיל — צריך להיזהר עם נפח. עדכוני הזמנה אפשר כבר עכשיו.

**4. קוד הנחה / תמריץ**
- האם לתת קוד הנחה לנוטשים (למשל "5% למסיימים עכשיו" או "משלוח חינם")? אפשר לייצר קודים ב-Shopify אוטומטית.

**5. הסכמה שיווקית (חוקי בישראל)**
- האם הלקוחות סימנו הסכמה לדיוור (מייל + SMS/WhatsApp) בצ'קאאוט? חוק הספאם מחייב הסכמה מפורשת.

**6. מיתוג (לעיצוב המיילים)**
- לוגו, צבעי מותג, וטון דיבור.

## 💡 סדר מומלץ
1. לאשר שיש Shopify Abandoned Checkouts (או למצוא חלופה) — בלי זה אין למי לשלוח.
2. לפתוח חשבון Resend (חינם עד ~3,000 מייל/חודש) ולתת API key.
3. להבהיר את סטטוס ה-WhatsApp (Business API או רגיל).

ברגע שיש את 3 אלה — אפשר לבנות משפך מלא עם תזמונים, תמריצים ומעקב.
